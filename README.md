# Award Bedeez

## Pages
- `/phone.html` : page publique de vote
- `/screen.html` : grand écran
- `/admin.html` : panneau de contrôle

## Nouveau panneau admin
Le panneau permet désormais de modifier en direct :
- le titre ;
- les sous-titres ;
- le texte du bouton de vote ;
- un message spécial ;
- la couleur et la taille du titre ;
- la couleur et la taille du sous-titre ;
- l'affichage du QR code ;
- l'affichage de la mascotte ;
- l'affichage de la jauge ;
- l'objectif ;
- le nombre de votes ;
- une animation WINNER plein écran.

Les changements sont diffusés en temps réel via Socket.IO.
